::: {.front card-id="card-6dbf69f8ba56c97e" tags="algebra, commutative-algebra"}
Regular Ring
:::

::: {.back card-id="card-6dbf69f8ba56c97e"}
$R$ is regular $\iff R$ is Noetherian and every finitely generated $R\dash$module has a finite resolution by finitely-generated projective $R\dash$modules.
:::

::: {.front card-id="card-3124a2802f44d313" tags="commutative-algebra"}
Dedekind Rings
:::

::: {.back card-id="card-3124a2802f44d313"}
Every ideal is projective.
:::

::: {.front card-id="card-0f2492cb599c5204" tags="algebra"}
Idempotent
:::

::: {.back card-id="card-0f2492cb599c5204"}
An element $x$ in a set with a closed binary operation $\cdot$ is *idempotent* iff $x\cdot x = x$.
:::
