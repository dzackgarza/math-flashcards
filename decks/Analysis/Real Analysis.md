::: {.front card-id="card-4da8ee7ee8fa8c36" tags="theorem"}
Fatou's Lemma
:::

::: {.back card-id="card-4da8ee7ee8fa8c36"}
If $\theset{f_n} \subset L^+$, then
$$
\int \liminf f_n \leq \liminf \int f_n
$$

- Pulling the limit out makes it bigger
- Pushing the limit in means integrating a smaller function, making the whole thing smaller.
:::

::: {.front card-id="card-959d01798e5675c8" tags="theorem"}
Egorov's Theorem
:::

::: {.back card-id="card-959d01798e5675c8"}
If $E\subset \RR^n$ is measurable, $m(E) > 0$, and $\theset{f_n}$ measurable with $f_k \to f$ with $f(x) < \infty$ existing and finite a.e., then $f_n\to f$ *almost uniformly*, i.e.
for all $\varepsilon > 0$ there exists a closed $F\subset E$ such that $m(E\setminus F)<\varepsilon$ and $f\converges{u}\to f$ on $F$.
:::

::: {.front card-id="card-ec45537586520293" tags="definition"}
Borel set
:::

::: {.back card-id="card-ec45537586520293"}
The smallest $\sigma\dash$algebra generated by the topology, i.e. every element is obtained by countable unions/intersections/complements of open sets.
:::

::: {.front card-id="card-195658c8dfc0cd99" tags="theorem"}
Dominated Convergence Theorem
:::

::: {.back card-id="card-195658c8dfc0cd99"}
If $\theset{f_n} \subset L^1$ and $f_n\to f$ a.e. with $\abs{f_n} \leq g \in L^1$ for every $n$, then
$$
\lim \int f_n = \int \lim f_n
$$
:::

::: {.front card-id="card-88f576b84be27921" tags="theorem"}
Monotone Convergence Theorem
:::

::: {.back card-id="card-88f576b84be27921"}
If $f_n \in L^+$ and $f_n\nearrow f$ a.e. then
$$
\lim \int f_n = \int \lim f_n
$$
:::

::: {.front card-id="card-0f91ecfaf2d85f3e" tags="definition"}
(Lebesgue) Measurable Function
:::

::: {.back card-id="card-0f91ecfaf2d85f3e"}
Let $E$ be measurable. A function $f:E\to\bar\RR$ is Lebesgue (resp. Borel) **measurable** iff for all $\alpha \in \RR$,
$$
S_\alpha \definedas \theset{ x\in E \suchthat f(x) > \alpha} = \inverseof{f}((\alpha, \infty]) \in \mathcal{M}_L \text{ (resp. } \mathcal{M}_B\text{)},
$$
the collection of Lebesgue (resp. Borel) measurable *sets*.

> Mnemonic: preimage of a ray should be a measurable set.
:::

::: {.front card-id="card-df7529951c584be6" tags="definition"}
Equivalent Characterizations of Completeness
:::

::: {.back card-id="card-df7529951c584be6"}
For a metric space $X$, *complete* means: every Cauchy sequence converges.
For a normed space $X$, the following are equivalent:

- $X$ is complete: every Cauchy sequence converges.
- Every absolutely convergent series converges: $\sum \norm{x_n} < \infty \implies \sum x_n$ converges in $X$.
:::

::: {.front card-id="card-68b12d35f383fd87" tags="formula"}
Bernoulli's Inequality
:::

::: {.back card-id="card-68b12d35f383fd87"}
$$
(1+x)^n \geq 1 + nx
$$
for all integers $n\geq 0$ and $x\geq -1$. If $n\geq 0$ is even, then this is valid for all $x\in \RR$.
Prove by induction.
More generally, $(1+x)^r \geq 1 + rx$ for real $r\geq 1$ and $x\geq -1$; for $0 < r < 1$ the inequality reverses.
:::

::: {.front card-id="card-ab45f41f8a332938" tags="definition"}
Uniform Continuity
:::

::: {.back card-id="card-ab45f41f8a332938"}
For $f: (X, d_1) \to (Y, d_2)$, for every $\varepsilon > 0$ there exists $\delta(\varepsilon) > 0$ such that for every $x,y\in X$, $$x\in B_\delta(y) \implies f(x) \in B_\varepsilon(f(y)).$$

> Slogan: continuity, but $\delta$ can be chosen independent of $x$.
:::

::: {.front card-id="card-2e8349c1d7c24daa" tags="proof"}
Proof of Borel-Cantelli Lemma
:::

::: {.back card-id="card-2e8349c1d7c24daa"}
*Proof of Borel Cantelli:*

- If $E = \limsup_j E_j$ with $\sum m(E_j) < \infty$ then $m(E) = 0$.
- If $E_j$ are measurable, then $\limsup_j E_j$ is measurable.
- If $\sum_j m(E_j) < \infty$, then $\sum_{j=N}^\infty m(E_j) \converges{N\to\infty}\to 0$ as the tail of a convergent sequence.
- $$E = \limsup_j E_j = \intersect_{k=1}^\infty \union_{j=k}^\infty E_j \implies E \subseteq \union_{j=k}^\infty E_j \quad \forall k $$
- $$E \subset \union_{j=k}^\infty E_j \implies m(E) \leq \sum_{j=k}^\infty m(E_j) \converges{k\to\infty}\to 0.$$
:::

::: {.front card-id="card-aa794acc7033d93a" tags="definition, important, analysis"}
Define $\limsup, \liminf$ for sequences of sets. What are their containments?
:::

::: {.back card-id="card-aa794acc7033d93a"}
$$\begin{align*}
\limsup_n A_n \definedas \intersect_n \union_{j\geq n} A_j&= \theset{x \suchthat x\in A_n \text{ for inf. many $n$}}  \\
\liminf_n A_n \definedas \union_n \intersect_{j\geq n} A_j &= \theset{x \suchthat x\in A_n \text{ for all except fin. many $n$}}  \\
\end{align*}$$

- Supremum: Union, $\limsup = \inf\sup$, in infinitely many
- Infimum: Intersection, $\liminf = \sup\inf$, eventually in
- $\liminf_n A_n \subseteq \limsup_n A_n$ since "all but finitely many" implies "infinitely often".
:::

::: {.front card-id="card-32521960d78ab719" tags="theorem"}
Arzela-Ascoli Theorem
:::

::: {.back card-id="card-32521960d78ab719"}
Let $K$ be a compact metric space and $\theset{f_n} \subset C(K)$.
If $\theset{f_n}$ is uniformly bounded and equicontinuous, then it has a uniformly convergent subsequence.

More generally, a family $\mcf \subset C(K)$ is relatively compact in $\qty{C(K), \norm{\wait}_\infty}$ iff $\mcf$ is uniformly bounded and equicontinuous.
On a compact $K$, equicontinuity is equivalent to uniform equicontinuity.
:::

::: {.front card-id="card-e1e89b54ee468a15" tags="formula"}
Cauchy-Schwarz Inequality
:::

::: {.back card-id="card-e1e89b54ee468a15"}
$$
\abs{\inner{f}{g}} \leq \norm{fg}_1 \leq \norm{f}_2 \norm{g}_2, \quad\text{i.e.}\quad
\int\abs{fg} \leq \sqrt{\int \abs{f}^2} \sqrt{\int \abs{g}^2}
$$
with equality iff $f \in \spanof_\CC(g)$.
:::

::: {.front card-id="card-d7de25ce0a616c70" tags="theorem"}
Minkowski's Inequality
:::

::: {.back card-id="card-d7de25ce0a616c70"}
For $1 \leq p \leq \infty$,
$$
\norm{f + g}_p \leq \norm{f}_p + \norm{g}_p
.$$
:::

::: {.front card-id="card-e8ddbe31eaa2b728" tags="formula"}
Holder's Inequality
:::

::: {.back card-id="card-e8ddbe31eaa2b728"}
$$\norm{fg}_1 \leq \norm{f}_p \norm{g}_q$$
:::

::: {.front card-id="card-237c11192101d406" tags="formula"}
Young's Inequality
:::

::: {.back card-id="card-237c11192101d406"}
For $1\leq p, q\leq r \leq \infty$ with ${1\over p} + {1\over q} - {1\over r} = 1$,
$$
\norm{f\ast g}_r \leq \norm{f}_p \norm{g}_q
.$$
Useful cases:
$$\begin{align*}
\norm{f\ast g}_1 & \leq \norm{f}_1 \norm{g}_1 \\
\norm{f\ast g}_p & \leq \norm{f}_1 \norm{g}_p \\
\norm{f\ast g}_\infty & \leq \norm{f}_p \norm{g}_q \quad \text{for } {1\over p} + {1\over q} = 1 \\
\norm{f\ast g}_\infty & \leq \norm{f}_2 \norm{g}_2
\end{align*}$$
:::

::: {.front card-id="card-489e4e9afe49de75" tags="definition"}
What is equicontinuity? Uniform equicontinuity?
:::

::: {.back card-id="card-489e4e9afe49de75"}
For $X, Y$ metric spaces and $\mcf$ a family of functions $X\to Y$, $\mcf$ is *equicontinuous at $x_0$* iff for every $\varepsilon > 0$ there exists a $\delta(\varepsilon, x_0)>0$ such that
$$x\in B_\delta(x_0) \implies f(x) \in B_\varepsilon(f(x_0))$$
for all $f \in \mcf$.

The family $\mcf$ is *uniformly equicontinuous* iff $\delta(\varepsilon)$ can be chosen depending only on $\varepsilon$, so that for every pair $x_1, x_2 \in X$ and every $f \in \mcf$,
$$x_1 \in B_\delta(x_2) \implies f(x_1) \in B_\varepsilon(f(x_2)).$$
:::

Convolution
:::

::: {.back card-id="card-3c94bfc64ec5d9c9"}
$$
(f\ast g)(\xi) = \int f(\xi - y)g(y) \, dy
$$

:::

::: {.back card-id="card-e4f1d4aa0b2f8ea4"}

:::

::: {.front card-id="card-1cbbd5dfc6a5b03c" tags="formula"}
Bessel's Inequality
:::

::: {.back card-id="card-1cbbd5dfc6a5b03c"}
For $x\in H$ a Hilbert space and $\theset{e_k}$ an orthonormal sequence,
$$
\sum \abs{\inner{x}{e_k}}^2 \leq \norm{x}^2

Proof idea:
$$
\left\|x-\sum_{n=1}^{N}\left\langle x, u_{n}\right\rangle u_{n}\right\|^{2}=\cdots
.$$

Riemann-Lebesgue Lemma
:::

::: {.back card-id="card-50b2ca62122fdbcd"}
If $f\in L^1$, then the Fourier transform satisfies $$\hat f(\xi) \converges{\abs{\xi}\to \infty}\to 0.$$

::: {.front card-id="card-315b6dfa5041fdcf" tags="definition"}
Null Set
:::

::: {.back card-id="card-315b6dfa5041fdcf"}
A set $A$ is *null* iff for every $\varepsilon>0$ there exists a cover $\theset{U_j}\covers A$ such that $\sum \mu(U_j) < \varepsilon$, i.e. $\mu(A) = 0$.
:::

::: {.front card-id="card-034794991fef7f7d" tags="fact"}
Characterizations of $D_f$, the set of discontinuities of functions
:::

::: {.back card-id="card-034794991fef7f7d"}
- Always $F_\sigma$: $D_f = \union_{n\geq 1} \theset{x \suchthat \omega_f(x) \geq {1\over n}}$ is a countable union of closed sets, where $\omega_f(x)$ is the oscillation of $f$ at $x$. $D_f$ need not be closed: $D_f = \QQ$ for Thomae's function.
- $f_n\to f$ pointwise with $f_n$ continuous $\implies D_f$ is meager.
- (Lebesgue criterion) For $f$ bounded on $[a, b]$: $f \in \mathcal{R}(a, b) \iff D_f$ is null.
- $f$ monotone $\implies D_f$ is countable, and $f$ is differentiable almost everywhere (Lebesgue).
:::

::: {.front card-id="card-83d99f66ed993726" tags="technique"}
Showing uniform convergence of a *sequence* of functions
:::

::: {.back card-id="card-83d99f66ed993726"}
Find $M_n$ independent of $x$ such that
$$
\abs{f_n(x) - f(x)} \leq M_n \to 0
$$
:::

::: {.front card-id="card-2a78e0bb1101dd0a" tags="technique"}
Showing uniform convergence of a *series* of functions
:::

::: {.back card-id="card-2a78e0bb1101dd0a"}
Weierstrass $M\dash$test: if there are $M_n$ independent of $x$ with $\abs{f_n(x)} \leq M_n$ for all $x\in A$ and $\sum M_n < \infty$, then $\sum f_n$ converges absolutely and uniformly on $A$.

Equivalently, $\sum_{n\geq 0} \norm{f_n}_{\infty, A} < \infty \implies \sum f_n$ converges absolutely and uniformly on $A$, where $\norm{f_n}_{\infty, A}\definedas\sup_{x\in A}\abs{f_n(x)}$.
:::

::: {.front card-id="card-33d4bf2bf6fce3b5" tags="definition"}
Uniform Convergence of a sequence of functions
:::

::: {.back card-id="card-33d4bf2bf6fce3b5"}
$\theset{f_n} \converges{u}\to f$ on $E$ iff for every $\varepsilon>0$ there exists an $N(\varepsilon)$ such that for all $n\geq N$ and for all $x\in E$, $\abs{f_n(x) - f(x)} < \varepsilon$.
Equivalently,
$$
\norm{f_n - f}_\infty \definedas \sup_{x\in E}\abs{f_n(x) - f(x)} \converges{n\to\infty}\to 0
.$$
:::

::: {.front card-id="card-f161e786abec12f3" tags="proof"}
Relationship between continuity and differentiability
:::

::: {.back card-id="card-f161e786abec12f3"}
Differentiability $\implies$ continuity:
$$
f(x) - f(x_0) = (x-x_0) \qty{ f(x)-f(x_0) \over x-x_0 } = (x-x_0) f'(x_0) \to 0
.$$
Not conversely: $f(x) = \abs{x}$.

Caratheodory Characterization
:::

::: {.back card-id="card-e26c09cee5e1bad5"}
$E\subseteq \RR^n$ is measurable $\iff$ for all $A\subset \RR^n$,
$m_*(A) = m_*(E\intersect A) + m_*(E\intersect A^c)$

::: {.front card-id="card-c46294406e171642" tags="theorem"}
Equivalent characterizations of measurability of a set
:::

::: {.back card-id="card-c46294406e171642"}
$E\subset \RR^n$ is measurable iff any of these conditions hold

- There exist closed $F\subseteq E$ with $m_*(E\setminus F) < \varepsilon \to 0$.
- (When $m_*(E) < \infty$) There exist *compact* $K\subseteq E$ with $m_*(E\setminus K) < \varepsilon \to 0$.
- There exist open $G\supset E$ with $m_*(G\setminus E)<\varepsilon \to 0$ (outer regular)
- $E = H \union Z$ with $H\in F_\sigma$ and $Z$ null
- $E = V\setminus Z$ with $V\in G_\delta$ and $Z$ null
:::

::: {.front card-id="card-d247665e263ecb4b" tags="definition"}
Definition: Measurability of a Set
:::

::: {.back card-id="card-d247665e263ecb4b"}
A set $E\subseteq \RR^n$ is *measurable* iff for every $\varepsilon>0$ there exists an open $G(\varepsilon) \supset E$ with $m_*(G(\varepsilon)\setminus E)<\varepsilon \to 0$ (outer regular).

::: {.front card-id="card-9cf17fa0c19ae4ef" tags="theorem"}
Lusin's Theorem
:::

::: {.back card-id="card-9cf17fa0c19ae4ef"}
If $f$ is measurable and finite-valued on a measurable $E$ with $m(E) < \infty$ then there exist closed sets $F\subset E$ such that $m(E\setminus F) < \varepsilon \to 0$ such that $f\mid_F$ is continuous.
:::

::: {.front card-id="card-7bce719707650024" tags="definition"}
Convergence in Measure
:::

::: {.back card-id="card-7bce719707650024"}
$f_k \to f$ *in measure* on $E$ iff for every $\alpha > 0$,
$$
\lim _{k \rightarrow \infty} m\qty{\theset{x \in E \suchthat \abs{f_k(x)-f(x)} >\alpha}}=0
.$$
:::

::: {.front card-id="card-5979542421630a15" tags="proof"}
How are convergence in measure and almost-everywhere convergence related?
:::

::: {.back card-id="card-5979542421630a15"}
On a finite measure space, almost-everywhere convergence implies convergence in measure: Egorov's theorem gives uniform convergence outside a set of arbitrarily small measure. Conversely, convergence in measure gives an almost-everywhere convergent subsequence: choose $n_k$ with $\mu(|f_{n_k}-f|>2^{-k})<2^{-k}$ and apply Borel–Cantelli. The full sequence need not converge almost everywhere.
:::

::: {.front card-id="card-1f66fb5d19d7ca5a" tags="definition"}
Definition: The Lebesgue Integral
:::

::: {.back card-id="card-1f66fb5d19d7ca5a"}
$$
\int f:=\sup \left\{\int \phi \suchthat 0 \leq \phi \leq f, \,\, \phi \text { simple }\right\}
.$$
:::

::: {.front card-id="card-19b7a6b64ef7919f" tags="definition"}
Chebyshev's Inequality
:::

::: {.back card-id="card-19b7a6b64ef7919f"}
$$
\mu\qty{\{x \in\RR^n \suchthat \abs{f(x)} \geq \alpha\}} \leq \qty{\norm{f}_p \over \alpha }^p \quad \forall \alpha, p
.$$
Take $p=1$ to obtain
$$
\mu\qty{\{x \in \RR^n\suchthat \abs{f(x)} \geq \alpha\}} \leq {1\over \alpha } \int \abs{f(x)} \, dx \quad \forall \alpha
.$$
:::

::: {.front card-id="card-217b54f71199df11" tags="proof"}
Proposition: If $f\geq 0$ and $\int f=0$, then $f=0$ almost everywhere.
:::

::: {.back card-id="card-217b54f71199df11"}
For each $n\geq1$, let $E_n=\{x:f(x)\geq 1/n\}$. Then $0=\int f\geq\mu(E_n)/n$, so $\mu(E_n)=0$. Since $\{f>0\}=\bigcup_{n\geq1}E_n$, it has measure zero.

The hypothesis $f \geq 0$ is needed: $f = \chi_{[0, 1]} - \chi_{[1, 2]}$ has $\int f = 0$.
The converse ($f = 0$ a.e. $\implies \int f = 0$) holds for simple functions and passes to the supremum.
:::

::: {.front card-id="card-1541c4af4bbc91b2" tags="technique"}
How to commute a sum and an integral
:::

::: {.back card-id="card-1541c4af4bbc91b2"}
$f_n \in L^1$ with $\sum \int \abs{f_n} < \infty$.

Proof: Use Fubini-Tonelli.
:::

::: {.front card-id="card-86b13568f4c9d30b" tags="proof"}
Proposition: $\sum \abs{f_n} \in L^1 \implies \sum \abs{f_n(x)} < \infty$ a.e.
:::

::: {.back card-id="card-86b13568f4c9d30b"}
Tonelli's theorem gives $\int\sum_n|f_n(x)|\,d\mu=\sum_n\int|f_n|\,d\mu<\infty$. A nonnegative function with finite integral is finite almost everywhere. Therefore $\sum_n|f_n(x)|<\infty$ almost everywhere.
:::

Uniform $\implies$ pointwise $\implies$ a.e. Convergence in norm is incomparable (but generally weaker).

::: {.front card-id="card-4e8d526fd74155d0" tags="counterexamples, example"}
A sequence of functions that converges pointwise and a.e. but not uniformly or in $L^1$.
:::

::: {.back card-id="card-4e8d526fd74155d0"}
Skateboard to infinity:
$$

$$

::: {.front card-id="card-6c046c9461489c2f" tags="counterexamples, example"}
A sequence of functions that converges a.e. but not in $L^1$, uniformly, or pointwise
:::

::: {.back card-id="card-6c046c9461489c2f"}

::: {.front card-id="card-572b3fa8dfb90c89" tags="counterexamples, example"}
A sequence of functions that converges in $L^1$ but not uniformly, pointwise, or a.e.
:::

::: {.back card-id="card-572b3fa8dfb90c89"}
The typewriter sequence ("cathode ray"): for $n = 2^k + j$ with $0 \leq j < 2^k$,
$$
f_n \definedas \chi_{\left[{j\over 2^k}, {j+1\over 2^k}\right]}
.$$
Then $\norm{f_n}_1 = 2^{-k} \to 0$, but for every $x\in [0, 1]$, $f_n(x) = 1$ for infinitely many $n$ and $f_n(x) = 0$ for infinitely many $n$, so $f_n(x)$ converges at no point of $[0, 1]$.

::: {.front card-id="card-38cdaad0b3abafe3" tags="theorem, important"}
Small Tails and Absolute Continuity
:::

::: {.back card-id="card-38cdaad0b3abafe3"}
Let $f\in L^1(\RR^n)$ and $\varepsilon> 0$.

1. Small Tails: there exists an $N$ such that $\int_{B_N^c} \abs{f} < \varepsilon$, where $B_N$ is the ball of radius $N$ about $0$.
2. Absolute Continuity: there exists a $\delta$ such that $m(E) < \delta \implies \int_E \abs{f} < \varepsilon$.
:::

::: {.front card-id="card-1d31f17fcfe7faaa" tags="theorem, proof"}
Continuity in $L^1$
:::

::: {.back card-id="card-1d31f17fcfe7faaa"}
$$
f \in L^{1} \Longrightarrow \lim _{h \rightarrow 0} \int|f(x+h)-f(x)|=0
.$$
Proof idea: $\varepsilon/3$ argument. Approximate $f$ in $L^1$ by a compactly supported continuous $g$. Then $g$ is uniformly continuous, which bounds the integrand of $\int \abs{g(x+h) - g(x)}$ uniformly on a fixed compact set for small $h$.
:::

::: {.front card-id="card-cb4fe50343d70648" tags="theorem"}
Tonelli
:::

::: {.back card-id="card-cb4fe50343d70648"}
Let $f(x, y)$ be non-negative and measurable on $\RR^{n}\cross \RR^k$.
Then for almost every $y\in \RR^k$,

1. The slice function $f^y(x) \definedas f(x, y)$ is measurable on $\RR^n$.
2. The function $F(y) \definedas \int_{\RR^n} f^y(x) \, dx$ is measurable on $\RR^k$.
3. $$\int_{\RR^{n+k}} f(\vector u) \, d\vector u = \int_{\RR^n} \qty{\int_{\RR^k} f^y(x) \,dx}\, dy$$ in any order (where the integral may be infinite.)

> Note: requires **non-negativity** and **measurability**, but not integrability.
:::

::: {.front card-id="card-aa6e0c0d563c6cf3" tags="theorem"}
Fubini
:::

::: {.back card-id="card-aa6e0c0d563c6cf3"}
Let $f(x, y) \in L^1(\RR^n\cross \RR^k)$.
Then for almost every $y\in \RR^k$,

1. The slice function $f^y(x)\definedas f(x ,y)$ is *integrable*, so $f^y \in L^1(\RR^n)$.
2. The function $F(y) \definedas \int_{\RR^n} f^y(x) \, dx$ is *integrable*, so $F\in L^1(\RR^{k})$.
3. $$\int_{\RR^{n+k}} f(\vector u) \, d\vector u = \int_{\RR^n} \qty{ \int_{\RR^k} f^y(x) \, dx} \, dy$$ in any order.

> Note: requires **integrability**, not just measurability, but doesn't require non-negativity.
:::

::: {.front card-id="card-77bf558ca1184654" tags="example"}
Is a composition of Lebesgue measurable functions measurable?
:::

::: {.back card-id="card-77bf558ca1184654"}
No:

- Take $f: [0, 1]\to [0, 1]$ the Cantor-Lebesgue function (monotonic and cts) and $C$ the Cantor set
- $f(C) = [0, 1]$, so define $g(x) = f(x) +x$ so $g:[0, 1] \to [0, 2]$ (strictly monotonic and cts, so a homeomorphism), so $\inverseof{g}$ is cts and thus measurable.
- $\mu(g(C)) = 1>0$: $f$ is constant on every interval in $C^c$, so $g$ maps $[0, 1]\setminus C$ to intervals of the same total length $1$, leaving measure $2 - 1 = 1$ for $g(C)$. So $g(C) \supseteq A$ a non-measurable subset
- $\inverseof{g}(A) \subset C$ with $\mu(C) = 0$ implies $\inverseof{g}(A)$ is a measurable set, so $\chi_{\inverseof{g}(A)}$ is a measurable function
- Then $k\definedas \chi_{\inverseof{g}(A)} \circ \inverseof{g}$ isn't measurable since
  $$
  \inverseof{k}(\theset{1}) = \inverseof{(\inverseof{g})}\qty{\inverseof{\chi_{\inverseof{g}(A)}}(\theset{1})} = \inverseof{(\inverseof{g})}(\inverseof{g}(A)) = g(\inverseof{g}(A)) = A
  $$
  is not a measurable set.

So even (measurable) $\circ$ (continuous) need not be measurable.
:::

::: {.front card-id="card-9a3b19434994dc9c" tags="facts, fact"}
Where is $x^p$ integrable in $\RR$? (Depending on $p$)
:::

::: {.back card-id="card-9a3b19434994dc9c"}
- $p > -1 \iff x^p \in L^1((0, 1))$
- $p < -1 \iff x^p \in L^1((1, \infty))$

Equivalently, the $p\dash$test:
$$\begin{align*}
\int_0^1 {1\over x^p} \, dx < \infty &\iff p < 1 \\
\int_1^\infty {1\over x^p} \, dx < \infty &\iff p > 1
\end{align*}$$
In particular, $x^p \notin L^1((0, \infty))$ for every $p$.
:::

:::

::: {.back card-id="card-7fcd186e8b0c1d0c"}
If $f: I\to \RR$ is continuous, then for every $\varepsilon$ there exists a polynomial $p_\varepsilon(x)$ such that $\norm{f - p_\varepsilon}_\infty < \varepsilon$.
