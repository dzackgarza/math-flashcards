What is a regular ring?
:::

::: {.back card-id="card-8e0d90c723907950"}
A Noetherian local ring $(R, \mfm_R)$ is **regular** iff $\mfm_R$ can be generated by $\dim R$ elements.

The minimal number of generators of $\mfm_R$, which is $\dim_k \mfm_R/\mfm_R^2$ for $k = R/\mfm_R$, equals its Krull dimension.

A Noetherian ring $R$ is **regular** iff $R_p$ is regular for every prime $p$.

Homological characterization (Auslander–Buchsbaum–Serre): a Noetherian local ring is regular iff it has finite global dimension.
If every finitely generated $R\dash$module over a Noetherian ring $R$ has a finite resolution by finitely generated projective $R\dash$modules, then $R$ is regular; conversely, if $R$ is regular of finite Krull dimension $d$, every finitely generated $R\dash$module has such a resolution of length at most $d$.
:::

::: {.front card-id="card-e6ea1195745e84d0"}
What is ${J ({R}) }$? How is it interpreted geometrically?
:::

::: {.back card-id="card-e6ea1195745e84d0"}
$${J ({R}) } \coloneqq\bigcap_{\mfm\in \operatorname{mSpec}R} \mfm= \bigcap_{M\in  {}_{R}\Mod\text{ simple}} \operatorname{Ann}_R(M)$$
If $R\in   {}_{k}\Mod^{\fg}$, so $R\cong k[x_1, \cdots, x_{n}]/I$, the ${\sqrt{0_{R}} } = {J ({R}) }$, so ${J ({R}) }$ measures how far away $I$ is from defining the ring of functions on some variety.
:::

::: {.front card-id="card-1c0e480d46b39946"}
What is a quasiregular element in a ring?
:::

::: {.back card-id="card-1c0e480d46b39946"}
$a\in R$ with $1-a\in R^{\times}$; ${J ({R}) }$ is the largest ideal with every element quasiregular.
:::

::: {.front card-id="card-15b8d6629dda4a15"}
What is the Artin-Rees lemma?
:::

::: {.back card-id="card-15b8d6629dda4a15"}
$I\normal R, N\leq M\in   {}_{R}\Mod\implies \exists C\in \ZZ$ such that
$$I^nM = I^{n-C}(I^CM \cap N)$$
:::

::: {.front card-id="card-3cd25976f78e1383"}
What is Krull's intersection theorem?
:::

::: {.back card-id="card-3cd25976f78e1383"}
For $I\normal R$ Noetherian with $I \subseteq {J ({R}) }$,
$$\bigcap_{n\geq 0} I^n = 0$$
Works for $R\in \mathsf{Loc}\mathsf{CRing}$ with $I\coloneqq\mfm_R$.
:::

::: {.front card-id="card-5efd7f40f3c655ba"}
What is the geometric interpretation of Krull's intersection theorem?
:::

::: {.back card-id="card-5efd7f40f3c655ba"}
Define $\Ord_{p} f$ as the smallest $n$ such that $f\in \mfm_p^n$ but $f\not\in \mfp^{n+1}$; then $\Ord_p(f) = \infty \iff f=0$.

There is no hypersurface passing though $p$ with arbitrarily high order of vanishing.

One can detect whether $n$ functions vanishing at $0\in {\mathbf{A}}^n$ generate a local coordinate system (so generate $\mfm_0$) by knowing their differentials (residues in ${\mathbf{T}}_0 {\mathbf{A}}^n = \mfm_0/\mfm_0^2$ are a vector space basis), like an implicit function theorem.
:::

::: {.front card-id="card-097dd4d13f029591" tags="definition, definitions"}
What is a reduced ring?
:::

::: {.back card-id="card-097dd4d13f029591"}
A ring $R$ is *reduced* $\iff R$ has no nonzero nilpotent elements, i.e. $x^n = 0 \implies x=0$. Equivalently, $x^2 = 0 \implies x=0$.
:::

::: {.front card-id="card-0f5febe6342680d7" tags="theorem"}
What is Nakayama's lemma?
:::

::: {.back card-id="card-0f5febe6342680d7"}
If $M \in \rmod$ is finitely generated and $I\normal R$ with $I \subseteq \mcj(R)$, then $$IM = M \implies M = 0.$$
General form: if $I\normal R$ and $M\in {}_{R}\Mod^\fg$ with $M=IM$, then $\exists i\in I$ such that $m=im$ for all $m\in M$. So if $I$ stabilizes $M$, then an individual $i\in I$ stabilizes all of $M$. If $I \subseteq \mcj(R)$, then $1-i$ is a unit and $(1-i)M = 0$, so $M=0$.

For $R$ local and $N$ finitely generated, $M\to N$ is surjective iff $M/\mfm_RM \to N/\mfm_R N$ is surjective as a map of vector spaces.
:::

::: {.front card-id="card-6b401eeaa58d4cd8"}
Give a categorical/homological corollary of Nakayama's lemma.
:::

::: {.back card-id="card-6b401eeaa58d4cd8"}
For $R$ Noetherian, $M\in   {}_{R}\Mod$ flat, then $M$ is free:

Take a presentation $K\hookrightarrow R^n \twoheadrightarrow M$, reduce to $k$ to get $K'\hookrightarrow k^n \twoheadrightarrow M'$ where $K'=0 \implies K=0$.

Thus flat coherent sheaves over a Noetherian scheme are vector bundles.
:::

::: {.front card-id="card-9e61733e26511ed3"}
What is Nakayama's lemma for a local ring?
:::

::: {.back card-id="card-9e61733e26511ed3"}
For $(R, \mfm_R)$ a local ring, minimal generators of $M\in   {}_{R}\Mod$ biject with $k\operatorname{mod}$ bases for $M/\mfm_R M$ where $k \coloneqq R/\mfm_R$.

Any two such sets of minimal generators for $M$ of size $n$ are related by a matrix in $\operatorname{GL}_n(R)$.
:::

::: {.front card-id="card-21be8565e8bde6eb"}
What is the geometric interpretation of Nakayama's lemma?
:::

::: {.back card-id="card-21be8565e8bde6eb"}
For any $\mcf\in    {}_{{\mathcal{O}}_X}\Mod$, regard stalks $\mcf_p \in   {}_{{\mathcal{O}}_{X, p}}\Mod$, then the fibers $\mcf(p) \coloneqq\mcf_p/\mfm_p \mcf_p$ are vector spaces and any basis for the fiber $\mcf(p)$ lifts to a minimal generating set for the stalk $\mcf_p$.

If $\mcf\leadsto E$ represents a vector bundle, then a basis for ${ \left.{{E}} \right|_{{p}} }$ can be lifted to a basis of global sections in some neighborhood of $p$.
:::

::: {.front card-id="card-35e7be527f6a0351"}
Give a geometric application of Nakayama's lemma.
:::

::: {.back card-id="card-35e7be527f6a0351"}
If $f:X\to Y$ is a projective morphism between quasiprojective varieties, then $f$ is an isomorphism iff $df_p$ is injective for all $p\in X$.
:::

::: {.front card-id="card-f6838cc818e5fa74"}
What is the going up theorem?
:::

::: {.back card-id="card-f6838cc818e5fa74"}
If $R\hookrightarrow S\in  {}_{\ZZ}  \mathsf{Alg}$ is an integral extension, then $\operatorname{Spec}S\to \operatorname{Spec}R$, and for every $p\in \operatorname{Spec}R$ there is a $\tilde p\in \operatorname{Spec}S$ such that $\tilde p \cap R = p$.
:::

::: {.front card-id="card-c3c4d762b57c058f" tags="theorem"}
State Noether normalization for a nonzero finitely generated algebra $A$ over a field $k$. What geometric conclusion follows for an affine integral variety of dimension $d$?
:::

::: {.back card-id="card-c3c4d762b57c058f"}
There are algebraically independent $t_1,\ldots,t_d\in A$, with $d=\dim A$, such that $A$ is finite as a module over $k[t_1,\ldots,t_d]$.

Thus every affine integral $k$-variety of dimension $d$ admits a finite surjective morphism to $\mathbb A^d_k$.
:::

::: {.front card-id="card-333bb97f5f81c327"}
What is Krull's theorem?
:::

::: {.back card-id="card-333bb97f5f81c327"}
Every nonzero ring has a maximal ideal.

Stronger version: every proper ideal is contained in a maximal ideal (can apply to $I=\left\langle{0}\right\rangle$).
:::

::: {.front card-id="card-fe04345520ea92cc"}
What is Krull's Hauptidealsatz?
:::

::: {.back card-id="card-fe04345520ea92cc"}
Let $R$ be a Noetherian ring and $a$ an element of $R$ which is neither a zero divisor nor a unit. Then every minimal prime ideal $P$ containing $a$ has height 1.
:::

::: {.front card-id="card-2e1939e74e2dff9e" tags="theorem"}
Zariski's Lemma
:::

::: {.back card-id="card-2e1939e74e2dff9e"}
If a field extension is finitely generated as a $k\dash$algebra then it is finite degree.
:::

Idempotent
:::

::: {.back card-id="card-cacc12c1d9815f7a"}
An element $x$ in a set with a closed binary operation $\cdot$ is *idempotent* iff $x\cdot x = x$.

::: {.front card-id="card-3e058eb429a38ac7" tags="definition"}
Definition: Primary Decomposition
:::

::: {.back card-id="card-3e058eb429a38ac7"}
In a Noetherian ring, every ideal $I$ can be written as a finite intersection $I=Q_1\cap\cdots\cap Q_r$ of primary ideals. An ideal $Q$ is primary if $ab\in Q$ and $a\notin Q$ imply $b^n\in Q$ for some $n\geq1$.
:::

::: {.front card-id="card-a09e66fbc55e26cc" tags="commutative-algebra"}
Comparison between maximal and prime ideals
:::

::: {.back card-id="card-a09e66fbc55e26cc"}
Every maximal ideal is prime. A prime ideal $\mathfrak p$ is maximal exactly when $R/\mathfrak p$ is a field; prime alone says $R/\mathfrak p$ is an integral domain. Geometrically, maximal ideals are closed points of $\operatorname{Spec}R$; other prime ideals can be generic points.
:::

::: {.front card-id="card-191c32e34e7db670" tags="definition"}
Definition: Height of an Ideal
:::

::: {.back card-id="card-191c32e34e7db670"}
The height of a prime ideal $\mathfrak p$ is the supremum of lengths of strict chains $\mathfrak p_0\subsetneq\cdots\subsetneq\mathfrak p_n=\mathfrak p$. For an ideal $I$, $\operatorname{ht}(I)=\inf\{\operatorname{ht}(\mathfrak p):\mathfrak p\supseteq I\text{ prime}\}$.
:::

::: {.front card-id="card-ee3d073c81750457"}
When is $M\in { {}_{k} \mathsf{Alg}}$?
:::

::: {.back card-id="card-ee3d073c81750457"}
Algebras are like "covers" of schemes:

Noncommutative case: $M\in { {}_{k}  \mathsf{Alg}}$ when $\exists f\in \mathsf{CRing}(k \to Z(M))$, so $f^*: \operatorname{Spec}Z(M) \to \operatorname{Spec}k$ where $Z(M)$ is the ring-theoretic center of $M$. This induces an action $\lambda . m \coloneqq f(\lambda)m$ using the ring multiplication in $M$.

Commutative case: $\exists f\in \mathsf{CRing}(k\to M)$ so $\operatorname{Spec}M\to \operatorname{Spec}k$.

In particular, $M\in   {}_{k}\Mod$ so there should be an action by "scalars" $k\curvearrowright M$.
:::

::: {.front card-id="theorem-generic-freeness" tags="theorem"}
Let $A$ be a Noetherian domain, $B$ a finite-type $A$-algebra, and $M$ a finite $B$-module. State generic freeness, specifying over which localized ring the module becomes free.
:::

::: {.back card-id="theorem-generic-freeness"}
There exists $0\ne a\in A$ such that $M_a$ is a free $A_a$-module. Its rank over $A_a$ need not be finite.
:::
