::: {.front card-id="card-e5b732b2176f7d0c" tags="definition"}
Definition: Reductive Group
:::

::: {.back card-id="card-e5b732b2176f7d0c"}
A connected smooth affine algebraic group $G$ over an algebraically closed field is reductive iff $R_u(G)=1$. Equivalently, $G$ has no nontrivial connected normal unipotent subgroup.
:::

::: {.front card-id="card-d81d0c4e36265ee6" tags="definition"}
Definition: Algebraic Group
:::

::: {.back card-id="card-d81d0c4e36265ee6"}
An algebraic group over a field $k$ is a group object in the category of $k$-varieties: multiplication $G\times_kG\to G$, inverse $G\to G$, and identity $\operatorname{Spec}k\to G$ are morphisms satisfying the group axioms.
:::

::: {.front card-id="card-93c8159957201abb"}
What is $\dim \operatorname{PGL}_n(\CC)$?
:::

::: {.back card-id="card-93c8159957201abb"}
$n^2 - 1$.
:::

::: {.front card-id="card-b597392c6e73090e" tags="definition"}
What is the definition of Affine algebraic group?
:::

::: {.back card-id="card-b597392c6e73090e"}
A linear algebraic group: a closed subgroup of $\operatorname{GL}_n(k)$, equivalently an affine group scheme of finite type over $k$.
:::

::: {.front card-id="card-04522d7c94a9c4a9" tags="definition"}
What is the definition of Group object?
:::

::: {.back card-id="card-04522d7c94a9c4a9"}
An object $G$ of a category with morphisms $m:G\times G\to G$, $e:1\to G$, and $i:G\to G$ satisfying the group axioms; an algebraic group is a group object in $k$-varieties.
:::

::: {.front card-id="card-d40746c773a22d50" tags="definition"}
What is the definition of Projective general linear group?
:::

::: {.back card-id="card-d40746c773a22d50"}
The quotient $\operatorname{PGL}_n(k)=\operatorname{GL}_n(k)/k^\times$, the automorphism group of projective space $\mathbf P^{n-1}_k$.
:::

::: {.front card-id="card-f5ba597b713da982" tags="definition"}
What is the definition of Unipotent group?
:::

::: {.back card-id="card-f5ba597b713da982"}
A linear algebraic group all of whose elements are unipotent, i.e. $g-1$ is nilpotent in some (equivalently every) faithful representation.
:::

::: {.front card-id="card-e9efe34317462fca" tags="definition"}
What is the definition of Unipotent radical?
:::

::: {.back card-id="card-e9efe34317462fca"}
The largest connected normal unipotent subgroup $R_u(G)$ of a linear algebraic group $G$.
:::
