::: {.front card-id="card-1fae5c68a5b71e1a" tags="theorem"}
Eisenstein's Criterion
:::

::: {.back card-id="card-1fae5c68a5b71e1a"}
If $f(x) = \displaystyle\sum_{i=0}^n a_i x^i \in \ZZ[x]$ and there is a prime $p$ such that

- $p$ divides every coefficient *except* $a_n$, i.e. $p \divides a_i$ for $i < n$ and $p \nmid a_n$, and
- $p^2$ does not divide $a_0$,

then $f$ is irreducible in $\QQ[x]$.
:::

::: {.front card-id="card-20ec5e3a579f2fc9" tags="definition"}
Algebraic Extension
:::

::: {.back card-id="card-20ec5e3a579f2fc9"}
A field extension $L/K$ is **algebraic** $\iff$ every $\alpha \in L$ is the root of some nonzero polynomial $f(x)\in K[x]$.
:::

::: {.front card-id="card-4e2c2bf2bc80c298" tags="definition"}
Normal Extension
:::

::: {.back card-id="card-4e2c2bf2bc80c298"}
An algebraic field extension $L/K$ is **normal** $\iff$ every irreducible $p(x) \in K[x]$ either has no roots in $L$ or splits into linear factors in $L[x]$.
Equivalently, $L$ is the splitting field over $K$ of a family of polynomials in $K[x]$.
:::

::: {.front card-id="card-dec5dda56d98bbd1" tags="definition"}
Separable Extension
:::

::: {.back card-id="card-dec5dda56d98bbd1"}
An algebraic field extension $L/K$ is **separable** $\iff$ for every $\alpha \in L$, the minimal polynomial $\min_\alpha(x)/K$ is separable, i.e. has no repeated root in an algebraic closure.
Since $\min_\alpha(x)$ is irreducible, this is equivalent to its derivative being nonzero.
:::

::: {.front card-id="card-613e2cdfb8df05dd" tags="notation, definition"}
$K(x)$
:::

::: {.back card-id="card-613e2cdfb8df05dd"}
The field of rational functions, i.e. ratios of polynomials, in the variable $x$;
$$K(x) = \theset{{P(x) \over Q(x)} \suchthat P,Q \in K[x],\, Q \neq 0}.$$
Example: $\CC(x)$ is the field of meromorphic functions on the Riemann sphere.
:::

::: {.front card-id="card-0127c9c24dd08308" tags="notation, definition"}
$K[x]$
:::

::: {.back card-id="card-0127c9c24dd08308"}
The algebra of polynomials in the variable $x$, i.e.
$$K[x] = \theset{\sum_{i=0}^n a_ix^i \suchthat n\in \ZZ^{\geq 0},\, a_i \in K}.$$
:::

::: {.front card-id="card-a664c8a8767cf47d" tags="formula"}
Cyclotomic Polynomial: $\Phi_p(x)$.
:::

::: {.back card-id="card-a664c8a8767cf47d"}
$$\Phi_p(x) = 1 + x + x^2 + \cdots + x^{p-1}.$$
:::

::: {.front card-id="card-74b845fed059abf7" tags="formula"}
Cyclotomic Polynomial: $\Phi_{2p}(x)$.
:::

::: {.back card-id="card-74b845fed059abf7"}
For $p$ an odd prime,
$$\Phi_{2p}(x) = 1 - x + x^2 - \cdots + x^{p-1}.$$
:::

::: {.front card-id="card-b1974bbe4e05fcb2" tags="definition"}
Definition: $K[\alpha]$ for $\alpha \in F \supset K$
:::

::: {.back card-id="card-b1974bbe4e05fcb2"}
The minimal subring of $F$ generated by $K$ and $\alpha$, i.e. $K[\alpha] = \theset{f(\alpha) \suchthat f\in K[x]}$.
:::

::: {.front card-id="card-758001b6a798d527" tags="definition"}
$K(\alpha)$ for $\alpha \in F\supset K$
:::

::: {.back card-id="card-758001b6a798d527"}
The minimal **subfield** of $F$ generated by $K$ and $\alpha$.
:::

::: {.front card-id="card-84ff43cad7796e2e" tags="definition"}
Conjugates of a root
:::

::: {.back card-id="card-84ff43cad7796e2e"}
For $\alpha\in L$, a **conjugate** of $\alpha$ is any other root of the minimal polynomial of $\alpha$.
:::

::: {.front card-id="card-e4835fa59a54b2db" tags="theorem"}
Four Characterizations of Galois extensions $K/F$.
:::

::: {.back card-id="card-e4835fa59a54b2db"}
1. $K$ is a splitting field of a separable polynomial in $F[x]$.
2. $K$ such that the fixed field of $\Aut(K/F)$ is exactly $K$.
3. $K$ such that $[K:F] = \abs{\Aut(K/F)}$.
4. $K$ such that $K/F$ is finite, normal, and separable.
:::

::: {.front card-id="card-6ea5ed839a013724" tags="definition"}
Definition of Galois group for a **finite** extension $K/F$.
:::

::: {.back card-id="card-6ea5ed839a013724"}
$K/F$ is Galois $\iff$ $\abs{\Aut(K/F)} = [K: F]$.
:::

::: {.front card-id="card-153c2779e0922b8f" tags="example"}
Example of a field extension that is not Galois.
:::

::: {.back card-id="card-153c2779e0922b8f"}
$K = \QQ(2^{1\over 3})/\QQ$, since $\abs{\Aut(K/\QQ)} = 1$ but this is a degree 3 extension.
:::

::: {.front card-id="card-c08cbd80bcd7183a" tags="definition"}
Definition: Primitive Root of Unity.
:::

::: {.back card-id="card-c08cbd80bcd7183a"}
$\zeta$ is a **primitive $n$th root of unity** iff $\zeta^n = 1$ and $n$ is the smallest such integer for which this holds.
:::

::: {.front card-id="card-4ffa54e96d133092" tags="theorem"}
Fundamental Theorem of Galois Theory
:::

::: {.back card-id="card-4ffa54e96d133092"}
Let $K/F$ and $G = \mathrm{Gal}(K/F)$, then there is an inclusion-reversing bijection
$$\begin{align*}
\{E \suchthat K/E/F\} \quad&\iff\quad \{H \suchthat 1\leq H \leq G\} \\
E &\mapsto \{\tau\in G \suchthat \tau\mid_E = \mathrm{id}\} \\
H &\mapsto \text{Fixed field of } H
\end{align*}$$
such that

1. Inclusion reversing: $E_1 \subseteq E_2 \iff H_2 \leq H_1$.
2. $\abs{H} = [K: E]$ and $[E:F] = [G: H]$.
3. $K/E$ is always Galois with $G(K/E) = H$.
4. $E/F$ is Galois $\iff$ $H\normal G$, in which case $G(E/F) \cong G/H$.
5. Compositum correspondences:
  - $E_1\intersect E_2$ corresponds to $\generators{H_1, H_2}$.
  - $E_1 E_2$ corresponds to $H_1\intersect H_2$.
:::

::: {.front card-id="card-fa03dea0a0913b2d" tags="definition"}
Definition: Algebraic Element
:::

::: {.back card-id="card-fa03dea0a0913b2d"}
If $L/K$ is a field extension then $\alpha \in L$ is **algebraic** iff there exists a $g\in K[x]$ such that $g(\alpha) = 0$.
:::

::: {.front card-id="card-5e13c1fe767b3506" tags="definition"}
Definition: irreducible polynomial
:::

::: {.back card-id="card-5e13c1fe767b3506"}
A polynomial $p(x) \in K[x]$ over a field $K$ is **irreducible** iff it is nonconstant ($\deg p \geq 1$) and $p(x)= q(x)r(x) \implies q(x)$ or $r(x)$ is constant, i.e. it can not be factored into two polynomials of smaller degrees.
:::

::: {.front card-id="card-6b6dd0660bbb55bf" tags="definition"}
Definition: splitting field of a polynomial $f\in k[x]$
:::

::: {.back card-id="card-6b6dd0660bbb55bf"}
The smallest extension $F/k$ such that $f$ splits into linear factors in $F[x]$.
:::

::: {.front card-id="card-396a7001ce39acee" tags="definition"}
Definition: algebraically closed.
:::

::: {.back card-id="card-396a7001ce39acee"}
Every nonconstant polynomial has a root.
:::

::: {.front card-id="card-d1a999a8a78c28e7" tags="definition"}
Definition: perfect field.
:::

::: {.back card-id="card-d1a999a8a78c28e7"}
Every irreducible polynomial is separable.

Equivalently, the characteristic is zero, or is $p$ where Frobenius is an automorphism.

> All characteristic zero or finite fields are perfect.
:::
