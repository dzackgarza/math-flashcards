::: {.front card-id="card-77f7f25db26962f8" tags="definitions"}
*Reduced* ring
:::

::: {.back card-id="card-77f7f25db26962f8"}
A ring $R$ is *reduced* $\iff R$ has no nonzero nilpotent elements $\iff x^2  = 0 \implies x=0$.
:::

::: {.front card-id="card-a3d20bf32e572733" tags="theorem"}
Nakayama's Lemma
:::

::: {.back card-id="card-a3d20bf32e572733"}
If $M \in \rmod$ is finitely generated and $I\normal R$ with $I \subseteq \mcj(R)$, then $$IM = M \implies M = 0.$$
:::
