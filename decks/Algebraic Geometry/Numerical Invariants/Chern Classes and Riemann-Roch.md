::: {.front card-id="rr-worked-curve-degree" tags="application"}
Let $C/\mathbb C$ be a smooth projective curve of genus $4$ and $L$ a line bundle of degree $9$. Compute $h^0(C,L)$ using Riemann–Roch and justify the required vanishing.
:::

::: {.back card-id="rr-worked-curve-degree"}
Riemann–Roch gives $\chi(L)=9+1-4=6$. Serre duality gives
$$h^1(L)=h^0(K_C\otimes L^{-1})=0,$$
since $\deg(K_C\otimes L^{-1})=6-9=-3$. Hence $h^0(L)=6$.
:::

::: {.front card-id="rr-worked-canonical-boundary" tags="application"}
On a smooth projective complex curve of genus $3$, compute $h^0(K_C)$ and $h^0(2K_C)$ by Riemann–Roch.
:::

::: {.back card-id="rr-worked-canonical-boundary"}
Since $\deg K_C=4$, Riemann–Roch gives $\chi(K_C)=2$ and $\chi(2K_C)=6$. Serre duality gives
$$h^1(K_C)=h^0(\mathcal O_C)=1,\qquad h^1(2K_C)=h^0(-K_C)=0.$$
Therefore $h^0(K_C)=3$ and $h^0(2K_C)=6$.
:::

::: {.front card-id="rr-worked-quartic" tags="application"}
Let $S\subset\mathbb P^3_{\mathbb C}$ be a smooth quartic surface with hyperplane class $H$. Compute $h^0(S,\mathcal O_S(2H))$ by Riemann–Roch.
:::

::: {.back card-id="rr-worked-quartic"}
Here $K_S=0$, $\chi(\mathcal O_S)=2$, and $H^2=4$. Thus
$$\chi(\mathcal O_S(2H))=2+\frac{(2H)^2}{2}=10.$$
The divisor $2H$ is ample, so Kodaira vanishing gives $H^i(S,\mathcal O_S(2H))=0$ for $i>0$. Hence $h^0(S,\mathcal O_S(2H))=10$.
:::

::: {.front card-id="rr-worked-plane-blowup" tags="application"}
Let $S=\operatorname{Bl}_p\mathbb P^2_{\mathbb C}$, with pullback line class $H$ and exceptional curve $E$. Compute $h^0(S,\mathcal O_S(3H-E))$ by Riemann–Roch and vanishing.
:::

::: {.back card-id="rr-worked-plane-blowup"}
For $D=3H-E$, use $K_S=-3H+E$, $H^2=1$, $HE=0$, and $E^2=-1$:
$$\chi(\mathcal O_S(D))=1+\frac{D(D-K_S)}2=1+\frac{18-2}{2}=9.$$
On this blowup, $aH-bE$ is ample when $a>b>0$. Thus $D-K_S=6H-2E$ is ample, and Kodaira vanishing gives $h^0(D)=9$. These sections are plane cubics through $p$.
:::

::: {.front card-id="rr-worked-hirzebruch-nef" tags="application"}
On $\mathbb F_2/\mathbb C$, let $S$ be the negative section and $F$ a fiber. Compute $h^0(\mathcal O(S+2F))$ using Riemann–Roch and a vanishing theorem.
:::

::: {.back card-id="rr-worked-hirzebruch-nef"}
Put $D=S+2F$. Since $S^2=-2$, $SF=1$, $F^2=0$, and $K=-2S-4F=-2D$,
$$D^2=2,\qquad\chi(\mathcal O(D))=1+\frac{D(3D)}2=4.$$
The nef cone is generated by $F$ and $S+2F$. Thus $D-K=3D$ is nef and big, with $(3D)^2=18$. Kawamata–Viehweg vanishing gives $h^0(D)=4$. The equality $(3D)S=0$ prevents the use of Kodaira's ample-twist hypothesis.
:::

::: {.front card-id="rr-worked-weak-del-pezzo" tags="application"}
Let $S/\mathbb C$ be a smooth projective surface with $-K_S$ nef and big, $K_S^2=d$, and $\chi(\mathcal O_S)=1$. Compute $h^0(-2K_S)$.
:::

::: {.back card-id="rr-worked-weak-del-pezzo"}
Riemann–Roch gives
$$\chi(\mathcal O_S(-2K_S))=1+\frac{(-2K_S)(-3K_S)}2=1+3d.$$
Write $-2K_S=K_S+(-3K_S)$. The divisor $-3K_S$ is nef and big, so Kawamata–Viehweg vanishing gives $h^0(-2K_S)=1+3d$.
:::

::: {.front card-id="rr-worked-abelian-surface" tags="application"}
Let $L$ be an ample line bundle of polarization type $(1,3)$ on a complex abelian surface $A$. Compute $h^0(A,L)$ by Riemann–Roch.
:::

::: {.back card-id="rr-worked-abelian-surface"}
The polarization has $L^2=2\cdot1\cdot3=6$. Since $K_A=0$ and $\chi(\mathcal O_A)=0$,
$$\chi(L)=\frac{L^2}{2}=3.$$
Kodaira vanishing applies to $L=K_A+L$, so $h^0(A,L)=3$.
:::

::: {.front card-id="rr-worked-quintic" tags="application"}
Let $X\subset\mathbb P^4_{\mathbb C}$ be a smooth quintic threefold, with hyperplane class $H$. Compute $h^0(X,\mathcal O_X(2H))$ using Riemann–Roch.
:::

::: {.back card-id="rr-worked-quintic"}
Adjunction gives $K_X=0$. From $c(T_X)=(1+H)^5/(1+5H)$, one gets $c_2(X)=10H^2$; also $H^3=5$. Hence
$$\chi(\mathcal O_X(2H))=\frac{(2H)^3}{6}+\frac{2Hc_2(X)}{12}
=\frac{40}{6}+\frac{100}{12}=15.$$
Kodaira vanishing applies because $2H$ is ample. Thus $h^0(X,\mathcal O_X(2H))=15$.
:::

::: {.front card-id="rr-worked-bundle-plane" tags="application"}
For $E=\mathcal O_{\mathbb P^2}(1)\oplus\mathcal O_{\mathbb P^2}(2)$ over $\mathbb C$, compute $\chi(E)$ by surface Riemann–Roch and then determine $h^0(E)$.
:::

::: {.back card-id="rr-worked-bundle-plane"}
With $H$ the line class, $c_1(E)=3H$, $c_2(E)=2H^2$, and $K_{\mathbb P^2}=-3H$. Thus
$$\chi(E)=2+\frac{(3H)(6H)}2-2=9.$$
Each summand is $K_{\mathbb P^2}$ twisted by an ample line bundle: $\mathcal O(1)=\mathcal O(K+4H)$ and $\mathcal O(2)=\mathcal O(K+5H)$. Kodaira vanishing on the summands gives $h^0(E)=9$.
:::

::: {.front card-id="rr-worked-nonvanishing" tags="application"}
On $\mathbb P^1_{\mathbb C}\times\mathbb P^1_{\mathbb C}$, compute $\chi(\mathcal O(-2,1))$ by Riemann–Roch and determine all its cohomology dimensions.
:::

::: {.back card-id="rr-worked-nonvanishing"}
For $D=(-2,1)$ and $K=(-2,-2)$,
$$\chi(\mathcal O(D))=1+\frac{D(D-K)}2=1+\frac{(-2,1)(0,3)}2=-2.$$
Künneth and the cohomology of $\mathbb P^1$ give
$$h^0(\mathcal O(-2,1))=0,\qquad
h^1(\mathcal O(-2,1))=h^1(\mathcal O_{\mathbb P^1}(-2))h^0(\mathcal O_{\mathbb P^1}(1))=2,\qquad
h^2(\mathcal O(-2,1))=0.$$
Thus the Euler characteristic includes a nonzero $H^1$ contribution.
:::

::: {.front card-id="formula-curve-vector-bundle-rr" tags="formula"}
For a rank-$r$ vector bundle $E$ on a smooth connected projective complex curve of genus $g$, compute $\chi(E)$.
:::

::: {.back card-id="formula-curve-vector-bundle-rr"}
$$\chi(E)=\deg E+r(1-g).$$
:::

::: {.front card-id="formula-curve-normal-degree" tags="formula"}
For a smooth connected curve $C\subset\mathbb P^n_{\mathbb C}$ of degree $d$ and genus $g$, compute $\deg N_{C/\mathbb P^n}$.
:::

::: {.back card-id="formula-curve-normal-degree"}
$$\deg N_{C/\mathbb P^n}=(n+1)d+2g-2.$$
:::

::: {.front card-id="formula-curve-normal-euler" tags="formula"}
For a smooth connected degree-$d$, genus-$g$ curve $C\subset\mathbb P^n_{\mathbb C}$, compute $\chi(N_{C/\mathbb P^n})$, including the case $n=3$.
:::

::: {.back card-id="formula-curve-normal-euler"}
$$\chi(N_{C/\mathbb P^n})=(n+1)d+(n-3)(1-g),\qquad \chi(N_{C/\mathbb P^3})=4d.$$
:::

::: {.front card-id="formula-surface-curve-normal" tags="formula"}
For a smooth connected curve $C$ of genus $g$ on a smooth projective complex surface $S$, compute the degree and Euler characteristic of $N_{C/S}$.
:::

::: {.back card-id="formula-surface-curve-normal"}
$$\deg N_{C/S}=C^2,\qquad \chi(N_{C/S})=C^2+1-g=\frac{C^2-K_SC}{2}.$$
:::

::: {.front card-id="formula-chern-sum-dual" tags="formula"}
For complex algebraic vector bundles $E,F$, compute $c(E\oplus F)$ and $c_i(E^\vee)$.
:::

::: {.back card-id="formula-chern-sum-dual"}
$$c(E\oplus F)=c(E)c(F),\qquad c_i(E^\vee)=(-1)^ic_i(E).$$
:::

::: {.front card-id="formula-chern-line-twist" tags="formula"}
For a rank-$r$ vector bundle $E$ and a line bundle $L$, set $\ell=c_1(L)$. Compute the first two Chern classes of $E\otimes L$.
:::

::: {.back card-id="formula-chern-line-twist"}
$$c_1(E\otimes L)=c_1(E)+r\ell,\qquad c_2(E\otimes L)=c_2(E)+(r-1)c_1(E)\ell+\binom r2\ell^2.$$
:::

::: {.front card-id="formula-chern-character-expansion" tags="formula"}
For a rank-$r$ vector bundle $E$, write $\operatorname{ch}(E)$ through codimension three in terms of $c_i=c_i(E)$.
:::

::: {.back card-id="formula-chern-character-expansion"}
$$\operatorname{ch}(E)=r+c_1+\frac{c_1^2-2c_2}{2}+\frac{c_1^3-3c_1c_2+3c_3}{6}+\cdots.$$
:::

::: {.front card-id="formula-todd-expansion" tags="formula"}
For a smooth complex variety $X$, write $\operatorname{td}(T_X)$ through codimension three, with $c_i=c_i(T_X)$.
:::

::: {.back card-id="formula-todd-expansion"}
$$\operatorname{td}(T_X)=1+\frac{c_1}{2}+\frac{c_1^2+c_2}{12}+\frac{c_1c_2}{24}+\cdots.$$
:::

::: {.front card-id="formula-complete-intersection-chern-canonical" tags="formula"}
For a smooth complete intersection $X\subset\mathbb P^n_{\mathbb C}$ of multidegree $(d_1,\ldots,d_r)$ and hyperplane class $H$, compute $K_X$, $c(T_X)$, and the top hyperplane intersection.
:::

::: {.back card-id="formula-complete-intersection-chern-canonical"}
$$K_X\sim\left(\sum_i d_i-n-1\right)H,\qquad c(T_X)=\frac{(1+H)^{n+1}}{\prod_i(1+d_iH)},\qquad \int_XH^{n-r}=\prod_i d_i.$$
:::

::: {.front card-id="formula-hypersurface-chern-classes" tags="formula"}
For a smooth degree-$d$ hypersurface $X\subset\mathbb P^n_{\mathbb C}$ with hyperplane class $H$, compute $c_1(T_X),c_2(T_X),c_3(T_X)$ in its Chow ring.
:::

::: {.back card-id="formula-hypersurface-chern-classes"}
$$\begin{aligned}c_1&=(n+1-d)H,\\c_2&=\left[\binom{n+1}{2}-(n+1)d+d^2\right]H^2,\\c_3&=\left[\binom{n+1}{3}-\binom{n+1}{2}d+(n+1)d^2-d^3\right]H^3.\end{aligned}$$
:::

::: {.front card-id="formula-surface-vector-bundle-rr" tags="formula"}
For a rank-$r$ vector bundle $E$ on a smooth projective complex surface $S$, compute $\chi(E)$ using its Chern classes.
:::

::: {.back card-id="formula-surface-vector-bundle-rr"}
$$\chi(E)=r\chi(\mathcal O_S)+\frac12c_1(E)(c_1(E)-K_S)-c_2(E).$$
:::
