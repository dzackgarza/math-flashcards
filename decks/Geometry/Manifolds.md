::: {.front card-id="dg-frobenius-integrability" tags="theorem application"}
State Frobenius integrability for a smooth constant-rank distribution. Give the differential-form criterion and test the plane field $\ker(dz-x\,dy)$ on $\mathbb R^3$.
:::

::: {.back card-id="dg-frobenius-integrability"}
A smooth rank-$r$ subbundle $D\subset TM$ is locally tangent to coordinate slices iff its sections are closed under Lie bracket:
$$[\Gamma(D),\Gamma(D)]\subset\Gamma(D).$$
Equivalently, its annihilator locally generated by $\alpha_1,\ldots,\alpha_{n-r}$ generates a differential ideal: each $d\alpha_i$ belongs to the ideal generated by the $\alpha_j$. For a nowhere-zero one-form $\alpha$, this is $\alpha\wedge d\alpha=0$.

For $\alpha=dz-x\,dy$, $d\alpha=-dx\wedge dy$ and $\alpha\wedge d\alpha=-dz\wedge dx\wedge dy\ne0$. Equivalently, $\partial_x,\partial_y+x\partial_z$ lie in $D$, but their bracket $\partial_z$ does not. This plane field has no integral surfaces.
:::

::: {.front card-id="dg-cartan-structure-gauss" tags="formula application"}
State Cartan's structure equations in a local orthonormal frame. State the Gauss equation for a surface in Euclidean three-space and recover the curvature of a round sphere.
:::

::: {.back card-id="dg-cartan-structure-gauss"}
Let $\theta^i$ be the dual coframe, with $\nabla e_j=\omega^i{}_j\otimes e_i$. For a metric connection, $\omega^i{}_j=-\omega^j{}_i$; torsion and curvature forms are
$$\Theta^i=d\theta^i+\omega^i{}_j\wedge\theta^j,\qquad
\Omega^i{}_j=d\omega^i{}_j+\omega^i{}_k\wedge\omega^k{}_j.$$
Levi–Civita has $\Theta^i=0$.

For an oriented surface in $\mathbb R^3$ with unit normal $n$, shape operator $S(X)=-(D_Xn)^\top$, and second fundamental form $B(X,Y)=g(SX,Y)$, Gauss gives, for orthonormal tangent $e_1,e_2$,
$$K=B(e_1,e_1)B(e_2,e_2)-B(e_1,e_2)^2=\det S.$$
On a radius-$r$ sphere with outward normal, $S=-r^{-1}\mathrm{id}$, hence $K=r^{-2}$. Reversing the normal changes both principal-curvature signs, not Gaussian curvature.
:::

::: {.front card-id="dg-metric-tensors-volume" tags="definition formula"}
Define a Riemannian metric and its coordinate transformation law. How does it give lengths, duality of vectors and covectors, and a volume form?
:::

::: {.back card-id="dg-metric-tensors-volume"}
A smooth section $g\in\Gamma(\operatorname{Sym}^2T^*M)$ with $g_p$ positive definite at every $p$. In coordinates,
$$g=g_{ij}\,dx^i\otimes dx^j,\qquad
g'_{ab}=\frac{\partial x^i}{\partial y^a}\frac{\partial x^j}{\partial y^b}g_{ij}.$$
Repeated indices are summed. The metric defines
$$v^\flat=g(v,-),\quad(\alpha^\sharp)^i=g^{ij}\alpha_j,\quad
L(\gamma)=\int\sqrt{g(\dot\gamma,\dot\gamma)}\,dt.$$
On an oriented $n$-manifold, in oriented coordinates,
$$dV_g=\sqrt{\det(g_{ij})}\,dx^1\wedge\cdots\wedge dx^n.$$
A nondegenerate symmetric form of mixed signature is pseudo-Riemannian; it is not a Riemannian metric.
:::

::: {.front card-id="dg-forms-cartan" tags="formula application"}
State the rules for exterior differentiation, contraction, and Lie differentiation, including Cartan's formula. Compute $\mathcal L_X(dx\wedge dy)$ for the radial field $X=x\partial_x+y\partial_y$.
:::

::: {.back card-id="dg-forms-cartan"}
For a $p$-form $\alpha$,
$$d^2=0,\quad d(\alpha\wedge\beta)=d\alpha\wedge\beta+(-1)^p\alpha\wedge d\beta,\quad f^*d=df^*,$$
$$\iota_X(\alpha\wedge\beta)=\iota_X\alpha\wedge\beta+(-1)^p\alpha\wedge\iota_X\beta,$$
$$\mathcal L_X=d\iota_X+\iota_Xd,\qquad [\mathcal L_X,d]=0,\qquad [\mathcal L_X,\iota_Y]=\iota_{[X,Y]}.$$
Here $\mathcal L_X$ differentiates pullback by the local flow, and $[X,Y]^i=X^j\partial_jY^i-Y^j\partial_jX^i$.

For $\omega=dx\wedge dy$,
$$\iota_X\omega=x\,dy-y\,dx,\qquad \mathcal L_X\omega=d(x\,dy-y\,dx)=2\omega.$$
The radial flow expands area. For a closed $\omega$, infinitesimal preservation is equivalent to $d(\iota_X\omega)=0$.
:::

::: {.front card-id="dg-connection-local-form" tags="definition formula"}
Define a connection on a smooth vector bundle, its local matrix, and its change under a change of frame. State parallel transport and the induced tensor-product and dual connections.
:::

::: {.back card-id="dg-connection-local-form"}
$$\nabla:\Gamma(E)\to\Omega^1(M,E),\qquad \nabla(fs)=df\otimes s+f\nabla s.$$
In a frame $e$ with column of coefficients $v$, $\nabla(ev)=e(dv+Av)$. If $e'=eG$,
$$A'=G^{-1}AG+G^{-1}dG.$$
Parallel transport along $\gamma$ solves $\dot v+A(\dot\gamma)v=0$ with a specified initial value.
$$\nabla(s\otimes t)=\nabla s\otimes t+s\otimes\nabla t,$$
$$d\langle\alpha,s\rangle=\langle\nabla\alpha,s\rangle+\langle\alpha,\nabla s\rangle.$$
Connections form an affine space over $\Omega^1(M,\operatorname{End}E)$: their difference is tensorial, whereas a connection itself is not $C^\infty$-linear in the section.
:::

::: {.front card-id="dg-curvature-bianchi" tags="definition formula application"}
Define curvature, covariant exterior differentiation, and the Bianchi identity for a connection. Compute a line-bundle example and distinguish flatness from trivial monodromy.
:::

::: {.back card-id="dg-curvature-bianchi"}
$$F_\nabla(X,Y)s=\nabla_X\nabla_Ys-\nabla_Y\nabla_Xs-\nabla_{[X,Y]}s.$$
Extend $\nabla$ by $d_\nabla(\alpha\otimes s)=d\alpha\otimes s+(-1)^{\deg\alpha}\alpha\wedge\nabla s$. Then
$$d_\nabla^2=F_\nabla\wedge-,\qquad F_\nabla=dA+A\wedge A,\qquad d_\nabla F_\nabla=0.$$
Under frame change $G$, $F'=G^{-1}FG$. For a line connection $d+x\,dy$ on $\mathbb R^2$, $F=dx\wedge dy$.

Flat means $F=0$, equivalently local parallel frames. On $S^1=\mathbb R/2\pi\mathbb Z$, $d+ia\,d\theta$ is flat but has holonomy $e^{-2\pi ia}$; it has a global parallel frame iff $a\in\mathbb Z$.
:::

::: {.front card-id="dg-torsion-lc-koszul" tags="definition theorem formula"}
Define torsion and metric compatibility for a connection on $TM$. Characterize the Levi–Civita connection and give the Koszul and Christoffel formulas.
:::

::: {.back card-id="dg-torsion-lc-koszul"}
$$T(X,Y)=\nabla_XY-\nabla_YX-[X,Y],\qquad
(\nabla_Xg)(Y,Z)=Xg(Y,Z)-g(\nabla_XY,Z)-g(Y,\nabla_XZ).$$
The Levi–Civita connection is the unique connection with $T=0$ and $\nabla g=0$. It satisfies
$$\begin{aligned}
2g(\nabla_XY,Z)={}&Xg(Y,Z)+Yg(Z,X)-Zg(X,Y)\\
&-g(X,[Y,Z])+g(Y,[Z,X])+g(Z,[X,Y]),
\end{aligned}$$
$$\Gamma^k_{ij}=\tfrac12g^{k\ell}(\partial_i g_{j\ell}+\partial_jg_{i\ell}-\partial_\ell g_{ij}).$$
In a coordinate frame, $T^k_{ij}=\Gamma^k_{ij}-\Gamma^k_{ji}$. Torsion is defined for a connection on the tangent bundle; an arbitrary vector bundle connection has curvature but no such torsion tensor without additional structure.
:::

::: {.front card-id="dg-polar-coordinates-flat" tags="application comparison"}
For the Euclidean metric $dr^2+r^2d\theta^2$ on the punctured plane, compute its nonzero Christoffel symbols and one curvature component. Do nonzero Christoffel symbols imply curvature?
:::

::: {.back card-id="dg-polar-coordinates-flat"}
$$\Gamma^r_{\theta\theta}=-r,\qquad
\Gamma^\theta_{r\theta}=\Gamma^\theta_{\theta r}=1/r.$$
Use $R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z$. Then
$$\nabla_r\nabla_\theta\partial_\theta=\nabla_r(-r\partial_r)=-\partial_r,$$
$$\nabla_\theta\nabla_r\partial_\theta
=\nabla_\theta(r^{-1}\partial_\theta)=-\partial_r,$$
so $R(\partial_r,\partial_\theta)\partial_\theta=0$. The metric is flat; its Christoffel symbols reflect a varying coordinate frame. Curvature is tensorial, Christoffel symbols are not.
:::

::: {.front card-id="dg-riemann-ricci-sectional" tags="definition formula"}
Fix $R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z$. Define sectional, Ricci, and scalar curvature. State the curvature symmetries and first Bianchi identity for Levi–Civita.
:::

::: {.back card-id="dg-riemann-ricci-sectional"}
For independent $u,v$ and an orthonormal basis $e_a$,
$$K(u\wedge v)=\frac{g(R(u,v)v,u)}{g(u,u)g(v,v)-g(u,v)^2},$$
$$\operatorname{Ric}(Y,Z)=\sum_a g(R(e_a,Y)Z,e_a),\qquad
\operatorname{Scal}=\sum_a\operatorname{Ric}(e_a,e_a)=2\sum_{a<b}K(e_a\wedge e_b).$$
For $R(X,Y,Z,W)=g(R(X,Y)Z,W)$,
$$R(X,Y,Z,W)=-R(Y,X,Z,W)=-R(X,Y,W,Z)=R(Z,W,X,Y),$$
$$R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0.$$
With this convention the round sphere has positive sectional curvature. Changing the definition of $R$ changes the associated contraction signs; keep the convention with the formulas.
:::

::: {.front card-id="dg-curvature-models-scaling" tags="comparison application"}
Compare constant sectional curvature, Einstein, Ricci-flat, and flat metrics. Compute Ricci and scalar curvature for space forms, and explain constant rescaling and product metrics.
:::

::: {.back card-id="dg-curvature-models-scaling"}
In real dimension $n$, constant sectional curvature $c$ means
$$R(X,Y)Z=c\big(g(Y,Z)X-g(X,Z)Y\big),\quad
\operatorname{Ric}=(n-1)c\,g,\quad\operatorname{Scal}=n(n-1)c.$$
Einstein means $\operatorname{Ric}=\lambda g$ for a constant $\lambda$; Ricci-flat means $\lambda=0$; flat means $R=0$.

| Metric | Sectional curvature |
| --- | --- |
| Round $S^n$ of radius $r$ | $1/r^2$ |
| Euclidean space or a flat torus | $0$ |
| Hyperbolic metric of radius scale $r$ | $-1/r^2$ |

For $g'=a^2g$, the Levi–Civita connection and $(1,3)$ tensor $R$ stay fixed; $K'=a^{-2}K$, $\operatorname{Ric}'=\operatorname{Ric}$ as a $(0,2)$ tensor, and $\operatorname{Scal}'=a^{-2}\operatorname{Scal}$.

Products have zero mixed sectional curvature and the direct sum of Ricci tensors. Unit $S^2\times S^2$ is Einstein with $\lambda=1$, but has sectional curvatures $1$ in factor planes and $0$ in mixed planes. A Ricci-flat K3 metric is not flat: a compact simply connected flat manifold cannot be a K3 surface.
:::

::: {.front card-id="dg-conformal-surface-gauss" tags="formula application"}
Compute Gaussian curvature for $g=e^{2u}(dx^2+dy^2)$. Apply it to the upper-half-plane metric and the stereographic round-sphere metric. State Gauss–Bonnet.
:::

::: {.back card-id="dg-conformal-surface-gauss"}
$$K=-e^{-2u}(u_{xx}+u_{yy}),\qquad\operatorname{Ric}=Kg,\quad\operatorname{Scal}=2K.$$
For $g=y^{-2}(dx^2+dy^2)$, $u=-\log y$, $\Delta u=y^{-2}$, so $K=-1$.

For $g=4(1+x^2+y^2)^{-2}(dx^2+dy^2)$,
$$u=\log2-\log(1+x^2+y^2),\quad\Delta u=\frac{-4}{(1+x^2+y^2)^2},\quad K=1.$$
For a compact oriented surface without boundary,
$$\int_MK\,dA=2\pi\chi(M).$$
A closed hyperbolic surface of genus $g\ge2$ therefore has area $4\pi(g-1)$.
:::

::: {.front card-id="dg-geodesics-completeness" tags="definition theorem application"}
Define geodesics, the exponential map, and geodesic completeness. State Hopf–Rinow for a connected Riemannian manifold. How do compactness and the punctured Euclidean plane fit?
:::

::: {.back card-id="dg-geodesics-completeness"}
$$\nabla_{\dot\gamma}\dot\gamma=0
\quad\Longleftrightarrow\quad
\ddot x^k+\Gamma^k_{ij}\dot x^i\dot x^j=0.$$
The geodesic with $\gamma(0)=p$, $\dot\gamma(0)=v$ defines $\exp_p(v)=\gamma(1)$ where it exists; $d(\exp_p)_0=\mathrm{id}$. Geodesic completeness means every geodesic extends for all real time.

Hopf–Rinow: metric completeness, geodesic completeness, and compactness of all closed bounded subsets are equivalent; they imply any two points can be joined by a minimizing geodesic. Every compact Riemannian manifold is complete. The punctured Euclidean plane is incomplete: a radial geodesic reaches the missing origin in finite time.
:::

::: {.front card-id="dg-almost-complex-integrability" tags="definition theorem comparison"}
Define an almost-complex structure, its Nijenhuis tensor, and the integrability criteria. Relate them to type decomposition and $\bar\partial$. What happens in real dimension two?
:::

::: {.back card-id="dg-almost-complex-integrability"}
$J\in\operatorname{End}(TM)$ with $J^2=-1$ gives
$$T_\mathbb CM=T^{1,0}\oplus T^{0,1},\qquad T^{1,0}=\ker(J-i).$$
For smooth $J$,
$$N_J(X,Y)=[JX,JY]-J[JX,Y]-J[X,JY]-[X,Y].$$
Newlander–Nirenberg gives the equivalences
$$\text{local holomorphic coordinates inducing }J
\Longleftrightarrow N_J=0
\Longleftrightarrow [T^{0,1},T^{0,1}]\subset T^{0,1}.$$
Equivalently, the projected operator $\bar\partial$ on functions has $\bar\partial^2=0$. Under these conditions $d=\partial+\bar\partial$ on all forms, with $\partial^2=\bar\partial^2=\partial\bar\partial+\bar\partial\partial=0$. For an arbitrary almost-complex structure, $d$ also has components of bidegrees $(2,-1)$ and $(-1,2)$.

In real dimension two $T^{0,1}$ has complex rank one and is involutive, so every smooth almost-complex structure is integrable.
:::

::: {.front card-id="dg-hermitian-kahler-equivalences" tags="definition comparison"}
Define a Hermitian metric and its fundamental form. Compare Hermitian, almost-Kähler, and Kähler structures, and give the Levi–Civita criterion for Kählerness.
:::

::: {.back card-id="dg-hermitian-kahler-equivalences"}
For an almost-complex $J$, compatibility is $g(JX,JY)=g(X,Y)$ and
$$\omega(X,Y)=g(JX,Y),\qquad g(X,Y)=\omega(X,JY).$$
On $T^{1,0}$ this gives a positive-definite Hermitian form, with local matrix $h_{i\bar j}$.

| Structure | Conditions |
| --- | --- |
| Almost-Hermitian | $J^2=-1$, $g$ compatible |
| Hermitian manifold | Almost-Hermitian and $J$ integrable |
| Almost-Kähler | Almost-Hermitian and $d\omega=0$ |
| Kähler | Hermitian and $d\omega=0$ |

For an almost-Hermitian structure,
$$\nabla^{\mathrm{LC}}J=0\Longleftrightarrow (N_J=0\text{ and }d\omega=0).$$
In complex dimension one every Hermitian metric is Kähler: its fundamental two-form is automatically closed. In higher dimension integrability and closedness are separate conditions.
:::

::: {.front card-id="dg-kahler-potentials-examples" tags="formula application counterexample"}
State the local-potential description of a Kähler form. Give Euclidean and Fubini–Study potentials, and a Hermitian metric that is not Kähler.
:::

::: {.back card-id="dg-kahler-potentials-examples"}
Locally,
$$\omega=i\partial\bar\partial\phi=i h_{i\bar j}\,dz^i\wedge d\bar z^j,\qquad h_{i\bar j}=\partial_i\partial_{\bar j}\phi>0.$$
Here the real metric is $g=2\operatorname{Re}(h_{i\bar j}\,dz^i\otimes d\bar z^j)$. Potentials differing by the real part of a holomorphic function give the same form.

- Euclidean: $\phi=\tfrac12\sum|z^i|^2$.
- Fubini–Study: $\phi=\log(1+\sum|z^i|^2)$ on an affine chart of $\mathbb P^n$; $[\omega/(2\pi)]=c_1(\mathcal O(1))$.
- On $\mathbb C^n$, $n\ge2$, let $g=e^{2x_1}g_0$, $\omega=e^{2x_1}\omega_0$. Then $d\omega=2e^{2x_1}dx_1\wedge\omega_0\ne0$: Hermitian but not Kähler.

Compactness is needed for the global Hodge-theoretic consequences; a local Kähler potential alone does not imply them.
:::

::: {.front card-id="dg-chern-lc-torsion" tags="comparison formula"}
Compare the Chern and Levi–Civita connections on a Hermitian manifold. How does the Chern torsion detect Kählerness? State the integrability condition for a holomorphic structure on a smooth complex vector bundle.
:::

::: {.back card-id="dg-chern-lc-torsion"}
The Chern connection of a Hermitian holomorphic bundle is characterized by metric compatibility and $\nabla^{0,1}=\bar\partial_E$. Its curvature has type $(1,1)$.

On $T^{1,0}M$, the Chern coefficients are
$$\Gamma^k_{ij}=h^{k\bar\ell}\partial_i h_{j\bar\ell},\qquad
T^k_{ij}=h^{k\bar\ell}(\partial_i h_{j\bar\ell}-\partial_j h_{i\bar\ell}).$$
The Chern connection preserves $J$ and $g$, but may have torsion. Levi–Civita preserves $g$ and has zero torsion, but may not preserve $J$. They agree under complexification iff the Hermitian metric is Kähler, equivalently the displayed Chern torsion vanishes.

A $(0,1)$-operator $D''$ on a smooth complex bundle over a complex manifold defines a holomorphic structure iff it satisfies the Leibniz rule and $(D'')^2=0$. For a connection, this is $F_\nabla^{0,2}=0$; it does not require full flatness.
:::

::: {.front card-id="dg-kahler-ricci-form" tags="formula application"}
For $\omega=i h_{i\bar j}dz^i\wedge d\bar z^j$, express the Ricci form, its cohomology class, and the Kähler–Einstein equation. Compute the Ricci form of Fubini–Study with potential $\log(1+|z|^2)$.
:::

::: {.back card-id="dg-kahler-ricci-form"}
With $\rho(X,Y)=\operatorname{Ric}(JX,Y)$,
$$\rho=-i\partial\bar\partial\log\det(h_{i\bar j}),\qquad
[\rho/(2\pi)]=c_1(T^{1,0}X)=-c_1(K_X).$$
Kähler–Einstein means $\operatorname{Ric}=\lambda g$, equivalently $\rho=\lambda\omega$. Ricci-flat means $\rho=0$, not $F_{T_X}=0$.

For Fubini–Study, $\det h=(1+|z|^2)^{-(n+1)}$, hence
$$\rho=(n+1)\omega_{\mathrm{FS}},\qquad\operatorname{Scal}=2n(n+1).$$
The scalar uses real dimension $2n$. Rescaling the metric changes the Einstein constant, so the normalization of $\omega_{\mathrm{FS}}$ matters.
:::

::: {.front card-id="dg-calabi-yau-existence" tags="theorem comparison"}
State the Calabi–Yau theorem in prescribed-Ricci-form language. What does $c_1(X)=0$ in real cohomology imply, and what does it not imply about an arbitrary Kähler metric?
:::

::: {.back card-id="dg-calabi-yau-existence"}
On a compact Kähler manifold, for each Kähler class $[\omega]$ and each real closed $(1,1)$-form $\rho_0$ representing $2\pi c_1(X)$, there is a unique Kähler metric in $[\omega]$ with Ricci form $\rho_0$.

If $c_1(X)=0\in H^2(X,\mathbb R)$, each Kähler class therefore contains a unique Ricci-flat metric. This does not make every metric in that class Ricci-flat, nor does it imply flatness or a holomorphically trivial canonical bundle. An Enriques surface has torsion nontrivial canonical bundle and real $c_1=0$.

For a fixed reference $\omega$, solve
$$\omega_\phi=\omega+i\partial\bar\partial\phi>0,\qquad
\omega_\phi^n=e^f\omega^n,\qquad\int_Xe^f\omega^n=\int_X\omega^n.$$
The potential is unique up to a constant. The volume-ratio identity gives $\rho(\omega_\phi)=\rho(\omega)-i\partial\bar\partial f$.
:::

::: {.front card-id="dg-hyperkahler-holonomy" tags="definition comparison example"}
Define a hyperkähler metric by complex structures and by holonomy. Explain its holomorphic symplectic form, Ricci-flatness, and relation to irreducible holomorphic symplectic manifolds.
:::

::: {.back card-id="dg-hyperkahler-holonomy"}
On a real $4n$-manifold, a hyperkähler structure is a Riemannian metric with parallel orthogonal endomorphisms $I,J,K$ satisfying
$$I^2=J^2=K^2=IJK=-1.$$
Equivalently, full holonomy lies in $\operatorname{Sp}(n)$. Parallelism implies integrability and closedness of $\omega_I,\omega_J,\omega_K$. For complex structure $I$,
$$\sigma=\omega_J+i\omega_K\in H^0(X,\Omega_I^2)$$
is parallel and nondegenerate. Since $\operatorname{Sp}(n)\subset\operatorname{SU}(2n)$, the metric is Ricci-flat. Every $aI+bJ+cK$ with $a^2+b^2+c^2=1$ is another compatible parallel complex structure.

A compact irreducible holomorphic symplectic manifold is simply connected, Kähler, and has $H^0(\Omega^2)=\mathbb C\sigma$ with $\sigma$ nondegenerate; its Ricci-flat metrics are hyperkähler. Flat quaternionic tori are hyperkähler but not irreducible holomorphic symplectic. K3 surfaces supply the compact simply connected complex-dimension-two example.
:::

::: {.front card-id="dg-de-rham-dolbeault-resolutions" tags="theorem comparison"}
State the de Rham and Dolbeault resolutions and the cohomology they compute. Explain why local exactness and fine sheaves both matter.
:::

::: {.back card-id="dg-de-rham-dolbeault-resolutions"}
For a smooth manifold,
$$0\to\mathbb R_M\to\mathcal A^0\xrightarrow d\mathcal A^1\xrightarrow d\cdots$$
is exact by the local Poincaré lemma and consists of fine sheaves after $\mathbb R_M$. Thus
$$H^k_{\mathrm{dR}}(M)\cong H^k(M,\mathbb R).$$
For a holomorphic vector bundle $E$ on a complex manifold,
$$0\to\Omega^p(E)\to\mathcal A^{p,0}(E)\xrightarrow{\bar\partial_E}\mathcal A^{p,1}(E)\to\cdots$$
is a fine resolution by the local $\bar\partial$-Poincaré lemma, giving
$$H^q(X,\Omega^p(E))\cong H^{p,q}_{\bar\partial}(X,E).$$
Local exactness makes these resolutions; partitions of unity make the smooth-form sheaves acyclic. Neither theorem requires compactness or a Kähler metric.
:::

::: {.front card-id="dg-hodge-star-laplacian" tags="definition theorem formula"}
Define the Hodge star, formal adjoint of $d$, and Hodge Laplacian. State the Hodge theorem on a compact oriented Riemannian manifold without boundary.
:::

::: {.back card-id="dg-hodge-star-laplacian"}
For real $k$-forms, $\alpha\wedge*\beta=\langle\alpha,\beta\rangle dV$ and $*^2=(-1)^{k(n-k)}$.
$$d^*|_{\Omega^k}=(-1)^{n(k+1)+1}*d*,\qquad\Delta_d=dd^*+d^*d.$$
On a compact oriented manifold without boundary,
$$\ker\Delta_d=\ker d\cap\ker d^*,\qquad
\Omega^k=\mathcal H^k\oplus d\Omega^{k-1}\oplus d^*\Omega^{k+1}.$$
The decomposition is $L^2$-orthogonal and every de Rham class has a unique harmonic representative, so $\mathcal H^k\cong H^k(M,\mathbb R)$. Without compactness or with boundary, this statement needs analytic conditions and, for boundary, boundary conditions.
:::

::: {.front card-id="dg-kahler-identities" tags="formula theorem application"}
State the Kähler identities for $L=\omega\wedge-$ and $\Lambda=L^*$. Relate the Laplacians and explain the resulting Hodge decomposition and a topological obstruction to Kählerness.
:::

::: {.back card-id="dg-kahler-identities"}
With $\omega(X,Y)=g(JX,Y)$,
$$[\Lambda,\partial]=i\bar\partial^*,\qquad
[\Lambda,\bar\partial]=-i\partial^*,\qquad
\Delta_d=2\Delta_\partial=2\Delta_{\bar\partial}.$$
On a compact Kähler manifold, harmonic forms split by type:
$$H^k(X,\mathbb C)=\bigoplus_{p+q=k}H^{p,q}(X),\qquad
H^{p,q}(X)\cong H^q(X,\Omega_X^p),\qquad\overline{H^{p,q}}=H^{q,p}.$$
Consequently every odd Betti number is even. The Hopf surface $(\mathbb C^2\setminus\{0\})/(z\sim2z)$ is diffeomorphic to $S^1\times S^3$, so $b_1=1$; it is complex but admits no Kähler metric.
:::

::: {.front card-id="dg-chern-weil-line-calculation" tags="formula application"}
State the Chern–Weil formulas for a Hermitian holomorphic bundle. Compute the curvature of $\mathcal O(1)$ with its Fubini–Study metric and its degree on $\mathbb P^1$.
:::

::: {.back card-id="dg-chern-weil-line-calculation"}
For the Chern curvature $F$,
$$c(E)=\left[\det\left(I+\frac{i}{2\pi}F\right)\right],\qquad
\operatorname{ch}(E)=\left[\operatorname{tr}\exp\left(\frac{i}{2\pi}F\right)\right].$$
These are closed forms; their cohomology classes are independent of the Hermitian metric. In a holomorphic line frame of squared norm $h$,
$$F=\bar\partial\partial\log h=-\partial\bar\partial\log h.$$
For $\mathcal O(1)$ on the standard affine chart, $h=(1+|z|^2)^{-1}$, hence $iF=\omega_{\mathrm{FS}}$ and
$$\deg\mathcal O(1)=\frac1{2\pi}\int_{\mathbb P^1}\omega_{\mathrm{FS}}=1.$$
On $\mathbb P^1$, $\omega_{\mathrm{FS}}=2r(1+r^2)^{-2}dr\wedge d\theta$; its integral is $2\pi$.
:::

::: {.front card-id="dg-bochner-ricci-consequence" tags="theorem application"}
State the integrated Bochner identity for a harmonic one-form on a compact Riemannian manifold without boundary. What do nonnegative and positive Ricci curvature imply?
:::

::: {.back card-id="dg-bochner-ricci-consequence"}
The Weitzenböck formula on one-forms is $\Delta_d=\nabla^*\nabla+\operatorname{Ric}$, with Ricci acting by metric duality. For harmonic $\alpha$,
$$0=\int_M\big(|\nabla\alpha|^2+\operatorname{Ric}(\alpha^\sharp,\alpha^\sharp)\big)\,dV.$$
If Ricci is nonnegative, every harmonic one-form is parallel. If Ricci is positive definite everywhere, $\alpha=0$, so $b_1=0$. Nonnegative Ricci alone does not force $b_1=0$: a flat torus has nonzero parallel one-forms.
:::

::: {.front card-id="card-6ac0da19537d1bf9" tags="definition"}
Embedding
:::

::: {.back card-id="card-6ac0da19537d1bf9"}
A topological embedding is a homeomorphism onto its image with the subspace topology. A smooth embedding is a smooth immersion that is also a topological embedding. Injectivity alone does not supply either the immersion condition or the subspace-topology condition.
:::

::: {.front card-id="card-85d8e3873abb3fcb" tags="definition"}
Immersion
:::

::: {.back card-id="card-85d8e3873abb3fcb"}
A smooth map $f:M\to N$ is an immersion if $d f_p:T_pM\to T_{f(p)}N$ is injective for every $p\in M$. Locally, it has the form $(x_1,\ldots,x_m)\mapsto(x_1,\ldots,x_m,0,\ldots,0)$ in suitable coordinates.
:::

::: {.front card-id="card-041a7aff1bdad643" tags="definition"}
Submersion
:::

::: {.back card-id="card-041a7aff1bdad643"}
A smooth map $f:M\to N$ is a submersion if $d f_p:T_pM\to T_{f(p)}N$ is surjective for every $p\in M$. Locally, it is a coordinate projection.
:::

::: {.front card-id="card-45bb001ecb537ab9" tags="definition"}
What is the definition of Holonomy?
:::

::: {.back card-id="card-45bb001ecb537ab9"}
For a connection on $E\to M$ and $p\in M$, $\operatorname{Hol}_p$ consists of parallel transports around piecewise smooth loops based at $p$. Restricted holonomy uses null-homotopic loops. Curvature controls restricted holonomy; a flat connection can still have nontrivial full holonomy through monodromy around noncontractible loops.
:::

::: {.front card-id="card-e843cbd8a58329f9" tags="definition"}
What is the definition of Smooth manifold?
:::

::: {.back card-id="card-e843cbd8a58329f9"}
A smooth manifold of dimension $n$ is a second-countable Hausdorff topological space locally homeomorphic to $\mathbb{R}^n$, equipped with an atlas whose transition maps are $C^\infty$.
:::
